# Session Service

Session Service предоставляет функциональность для получения сессий пользователей из Redis или PostgreSQL. 
Если сессия отсутствует в кэше Redis, сервис запрашивает данные из базы данных и кеширует их.

## Архитектура

Проект разделен на три слоя:

- **Handlers**: Обрабатывают HTTP-запросы и вызывают методы сервисного слоя.
- **Service**: Реализует бизнес-логику, работая с Redis и вызывая методы репозитория.
- **Repository**: Отвечает за взаимодействие с базой данных PostgreSQL.

## Работа с Redis TTl

Сервис проверяет наличие сессии в Redis перед выполнением запроса в базу данных.
Если сессия найдена в кэше, она немедленно возвращается. 
В противном случае данные загружаются из PostgreSQL и кешируются в Redis на (ttl) для ускорения последующих запросов.
